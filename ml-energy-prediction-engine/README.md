# Hourly Renewable Energy Production Prediction Engine

**Status: core pipeline + API + UI working end to end. Full README (architecture diagram, results writeup, limitations, interview prep) to be completed as part of Thursday's review/polish pass.**

## What this is

Predicts **next-hour** Wind/Solar energy production from recent historical readings and calendar
information, using a Gradient Boosting model trained on ~51K hourly records (2020-2025).

## Quick start

```bash
pip install -r requirements.txt

# 1. Train the model (only needed once - artifacts are already in models/)
cd src && python3 train.py && cd ..

# 2. Start the prediction API
cd api && uvicorn main:app --reload --port 8000

# 3. In a second terminal, start the UI
cd app && python3 app.py
# Gradio UI: http://127.0.0.1:7860
# API docs (auto-generated by FastAPI): http://127.0.0.1:8000/docs
```

## Run the tests

```bash
python3 -m pytest tests/ -v
```

## Try the API directly

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"source":"Wind","day_name":"Monday","start_hour":14,"day_of_year":200,"year":2025,"production_lag_1":7200,"production_lag_24":6800,"production_lag_168":6500}'
```

Or run the external-consumer example: `python3 examples/consume_api.py`

## Project structure

```
data/          raw dataset
notebooks/     original data profiling notebook
src/           preprocessing.py, feature_engineering.py, split.py, train.py
models/        saved model + preprocessor + feature config (produced by train.py)
api/           FastAPI service (main.py, schemas.py)
app/           Gradio frontend
examples/      example of an external app calling the API
tests/         pytest suite for the API
```
